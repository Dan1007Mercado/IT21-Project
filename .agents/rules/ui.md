# INTSEC UI Rules

Use Filament for the administrator/security operations interface.

Prefer native Filament components over custom components when equivalent functionality exists.

Use Filament Resources for entity management.

Use Filament Widgets for dashboard statistics and charts.

Use filters, search, sorting, badges, actions, and notifications to make security data practical to investigate.

Security severity should be visually distinguishable.

Incident status should be clearly visible.

Destructive or security-sensitive actions should require confirmation where appropriate.

Do not hardcode dashboard statistics.

Do not make the interface dependent on fake placeholder values.

The interface should be professional and appropriate for an information-security monitoring system rather than a generic CRUD application.

Avoid unnecessary UI complexity that is not required by the project proposal.
